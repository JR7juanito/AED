💡 OPCIONALES - Para desarrollo local:
═══════════════════════════════════════════════════════════════════

Si quieres editar localmente:

1. Instalar Rust/Cargo:
   https://rustup.rs/

2. Instalar mdBook:
   cargo install mdbook

3. Servir localmente:
   cd AED-Apuntes
   mdbook serve
   → Abre: http://localhost:3000

4. Editar archivos .md en src/
   → mdbook serve se recarga automáticamente

5. Push a GitHub:
   git add .
   git commit -m "descripción"
   git push origin main
   → ¡GitHub Pages se actualiza automáticamente!
