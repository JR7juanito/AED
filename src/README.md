# Algoritmos y Estructuras de Datos

Bienvenido a los apuntes del curso **Algoritmos y Estructuras de Datos** del Departamento de Ciencias de la Computación de la Universidad de Chile.

## 📚 Contenido

Este recurso contiene:

- **10 Temas principales** cubriendo conceptos fundamentales
- **Ejercicios prácticos** para cada tema
- **Ejemplos en Python** con código ejecutable
- **Análisis de complejidad** y optimizaciones

## 🎯 Temas Cubiertos

1. **Introducción** - Conceptos básicos y terminología
2. **Métodos Matemáticos** - Análisis de algoritmos y complejidad
3. **Diseño de Algoritmos** - Estrategias y patrones eficientes
4. **Estructuras de Datos Elementales** - Arreglos, listas enlazadas
5. **Pilas, Colas y Colas de Prioridad** - Estructuras especializadas
6. **Diccionarios** - Tablas hash y búsqueda
7. **Ordenación** - Algoritmos de sorting
8. **Búsqueda en Texto** - Pattern matching
9. **Compresión de Datos** - Algoritmos de compresión
10. **Grafos** - Algoritmos en grafos

## 🚀 Cómo usar estos apuntes

Los apuntes están organizados por capítulos con:
- Explicaciones teóricas
- Ejemplos de código en Python
- Ejercicios propuestos
- Referencias a algoritmos clásicos
